# Banner artwork

The banner uses an original SVG layout with geometric mountain artwork and a coral-red accent. `celestehaptic-banner.svg` is the editable source; `celestehaptic-banner.png` is the rendered version displayed on GitHub. `download-macos.svg` is the download button.

The white DualSense photograph is official Sony product artwork, used with its original transparent background and without a color tint.

- [PlayStation DualSense product page](https://www.playstation.com/en-us/accessories/dualsense-wireless-controller/)
- [Original image](https://gmedia.playstation.com/is/image/SIEPDC/dualsense-controller-product-thumbnail-01-en-14sep21?fmt=png-alpha&wid=1000)

Controller artwork © Sony Interactive Entertainment. It identifies the supported controller and is not covered by this repository’s MIT software license. The mountain illustration is original and uses no Celeste game assets.
