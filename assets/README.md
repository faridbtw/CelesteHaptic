# Banner artwork

The banner uses the actual mountain from Celeste’s title screen, captured from the local game during the startup test. `celeste-title-mountain.png` is a crop of that capture, excluding the game title, performance overlay, and window borders. The mountain is not generated or redrawn.

`celestehaptic-banner.svg` contains the editable layout, with the smaller controller positioned beside the text so the summit remains visible. `celestehaptic-game-mountain-banner.png` is the version displayed on GitHub. `download-macos.svg` is the download button.

Celeste title-screen imagery belongs to Celeste’s creators. [Official Celeste website](https://www.celestegame.com/). It is used here only as promotional imagery identifying the supported game and is not covered by this repository’s MIT software license.

The white DualSense photograph is official Sony product artwork, used with its original transparent background and without a color tint.

- [PlayStation DualSense product page](https://www.playstation.com/en-us/accessories/dualsense-wireless-controller/)
- [Original image](https://gmedia.playstation.com/is/image/SIEPDC/dualsense-controller-product-thumbnail-01-en-14sep21?fmt=png-alpha&wid=1000)
